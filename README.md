# 🏪 超商大亨 (Convenience Store Tycoon)

一款結合 2.5D 等角透視店面、台灣在地國民品牌商品、五大批發商動態議價與完整進銷存經營模擬的 Flutter 獨立遊戲。

---

## 🌟 核心特色 (Key Features)

1. **🏢 2.5D 等角透視門市現場 (Isometric 2.5D Store View)**
   - 包含收銀櫃台、雙面零食架、低溫飲料冷藏櫃、熟食便當加熱台、現煮咖啡吧台。
   - 動態顧客尋路、排隊結帳、氣泡對話與跳錢浮動動畫。
   - 支援自由添購與升級店面陳列設備。

2. **🧃 台灣在地國民品牌與商品庫 (Authentic Brands & Products)**
   - 收錄義美食品、統一企業、黑松、鮮食中央廚房、UCC 等代表性品牌。
   - 包含義美小泡芙、茶裏王、麥香奶茶、統一布丁、滿漢大餐、奮起湖便當、茶葉蛋、現煮拿鐵等 16 款國民商品。

3. **🚚 五大批發商地圖與 AI 動態議價 (Dynamic Sourcing & Bargaining)**
   - **宏泰老糧行 (老李)**：童叟無欺的傳統雜貨批發。
   - **統一企業經銷 (王課長)**：合約規範嚴謹的量販通路。
   - **義美食品物流 (林經理)**：講究品質與長期合作的專營商。
   - **鮮食中央廚房 (陳廠長)**：極短賞味期的鮮食便當物流。
   - **UCC 商用咖啡部 (Sofia)**：高毛利精品咖啡原料總監。
   - 支援自然語言對話動態議價（結合本地 LLM / 規則備援機制）。

4. **🗺️ 四大主線任務推進章節 (4-Stage Progression Loop)**
   - **第一章：巷弄小雜貨**（熟悉基本進銷存、累積第一桶金）
   - **第二章：現代化超商**（添購冷藏櫃、引進國民飲料）
   - **第三章：24H 全日無休旗艦店**（鮮食熟食、三班輪值排班健檢）
   - **第四章：商圈連鎖霸王**（全品項制霸、單日營收登頂）

5. **📊 深度經營管理系統 (Deep Tycoon Simulation)**
   - 每日損益結算與現金流管理（租金、薪資、進貨成本、水電損耗）。
   - 三班制人事排班健檢（早班、中班、大夜班）與士氣/疲勞管理。
   - 鮮食賞味期批次先進先出 (FIFO) 與過期報廢損耗。
   - 破產保護與連鎖週轉不靈警示。

## 🛠️ 開發與執行 (Development)

### 環境需求
- Flutter SDK >= 3.11.5
- Dart SDK >= 3.11.5

### 安裝與啟動
```bash
# 取得套件依賴
flutter pub get

# 執行測試套件 (48 項回歸與功能測試)
flutter test

# 啟動應用程式 (Windows 桌面)
flutter run -d windows

# 或啟動 Web 版
flutter run -d chrome
```

## 🧪 測試涵蓋 (Testing)
本專案包含嚴謹的單元測試與遊玩迴圈回歸測試：
- `test/playthrough_test.dart`：45 天持續營運迴圈、破產條件與主線解鎖驗證。
- `test/progression_test.dart`：商品庫解鎖、主線章節領獎與存檔還原。
- `test/simulation_test.dart`：人流需求、排班覆蓋、FIFO 鮮食損耗與設備升級。
- `test/widget_test.dart`：五大分頁 UI 互動、排班健檢與覆蓋圖長條互動。
